# SYNTHETIC CKEA corpus

Every document here is fictional and exists only to demonstrate CKEA. None of it is real
clinical guidance, and none of it may be used for patient care.

Layout: `<area>/<source>/v<version>.md`. Each file has YAML front matter (source_id, title,
source_type, publisher, version, published_date, synthetic). Watchlist entries in
`config/watchlist.yaml` point at the `<area>/<source>` directories.
